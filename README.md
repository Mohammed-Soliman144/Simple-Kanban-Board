# Simple Kanban Board

A lightweight task management application built with **HTML5, CSS3, and Vanilla JavaScript**. It allows users to organize tasks across workflow stages, manage task details, and update task positions through drag-and-drop interactions.

The project focuses on practicing core frontend development concepts, including DOM manipulation, event handling, application state management, dynamic UI updates, and the native HTML Drag and Drop API.

## Features

- **Create Tasks:** Add new tasks to the board.
- **Edit Tasks:** Modify existing task information.
- **Delete Tasks:** Remove tasks from the board.
- **Task Counters:** Dynamically display and update the number of tasks.
- **Drag and Drop:** Move tasks between workflow columns using the native HTML Drag and Drop API.
- **Task Organization:** Manage tasks across different workflow stages.
- **Notifications Toast:** appears animated toast within all CRUD operations.

## Tech Stack

- **HTML5:** Application structure and markup.
- **CSS3:** Styling, layout, and visual presentation.
- **JavaScript (ES6+):** Application logic, DOM manipulation, and event handling.
- **HTML Drag and Drop API:** Native drag-and-drop interactions.

This project provided practical experience with:

- Managing application state with JavaScript.

## Getting Started

### Prerequisites

A modern web browser is sufficient to run this application.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Mohammed-Soliman144/Simple-Kanban-Board.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Simple-Kanban-Board
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
